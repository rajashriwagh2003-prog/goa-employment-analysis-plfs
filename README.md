
# Goa Employment Analysis using PLFS Data

## 📌 Project Overview

This project analyzes employment and labour market outcomes in Goa using data from the Periodic Labour Force Survey (PLFS).

The analysis focuses on employment status, gender differences, rural-urban distribution, and key labour market indicators for the population aged 15–59 years.

## 🎯 Objectives

* Analyze employment status in Goa.
* Compare employment patterns by gender.
* Examine rural and urban distribution.
* Calculate key labour market indicators.
* Explore differences between North Goa and South Goa.

## 🛠️ Tools & Technologies

* R
* RStudio
* PLFS Data
* Data Cleaning & Preparation
* Statistical Analysis
* Data Visualization
* ggplot2

## 📊 Key Analysis Areas

* Employment Status
* Labour Force Participation Rate (LFPR)
* Worker Population Ratio (WPR)
* Unemployment Rate (UR)
* Gender-wise analysis
* Rural–Urban analysis
* North Goa vs South Goa comparison

## 📈 Key Findings

The analysis identified differences in employment status across gender and geographic groups in Goa.

Further statistical analysis was used to examine the relationship between gender and employment status.
